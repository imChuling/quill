# Listening test data archive

The auditable source of every human-experiment number in the paper. `analyze_listening.py` recomputes each number from the anonymised CSVs
and writes `listening_stats.json` for reconciliation with the paper.

## Files

| File | Contents |
|---|---|
| `responses_main.csv` | main listening test (N=13) per-participant answers, anonymous IDs P01–P13 |
| `responses_abx.csv` | ABX (N=18) per-participant per-trial answers, anonymous IDs A01–A18 |
| `analyze_listening.py` | statistics script (binomial / Bonferroni / Wilcoxon) |
| `listening_stats.json` | script output, maps one-to-one to the numbers in the paper |

## Data format

`responses_main.csv`:
```
participant_id,musical_training,q_expressive,q_style_distinct
P01,1,labeled,yes
```
- `musical_training`: 1=formal musical training
- `q_expressive`: labeled / plain (which version is more expressive)
- `q_style_distinct`: yes / no (whether a different playing style is heard after switching the behaviour source)

`responses_abx.csv`:
```
participant_id,trial_id,response
A01,1,match
```
- `trial_id`: 1–6
- `response`: match (chose the candidate with the same behaviour source) / nonmatch / unsure

## Collection procedure and exclusion rules (specified in advance)

- Stimuli were presented on HTML pages generated by `tools/build_listening_study.py` / `tools/build_abx_study.py`;
  **the stimulus order was fixed for all participants, with no per-participant
  counterbalancing** (a limitation, disclosed in the paper).
- `unsure` answers in the ABX are excluded from the accuracy statistics (paper N=107 valid = 108 − 1 unsure).
- Anonymisation: only sequential IDs and training status are kept; no names, contact details or response times.

## Recomputation

```
conda run -n mt python eval/listening/analyze_listening.py
```
